# Assignment suggestion

Generated by `python tools/team_tools.py suggest`. **This is a suggestion, not a decision.** The maintainer reviews it, changes `assignments.csv` where needed (and notes why in `decision_note`), and then creates the issues.

Parameters: growth bonus on. Fit is a number from 0 to 1 built from each member's skill levels (primary skills count fully, secondary skills half). It describes how well a task matches current skills. It is not a rating of a person.

**No hourly capacity model.** Size is a relative complexity label (S=1, M=2, L=3), not a time estimate. The tool balances task count and complexity, and gives every member a meaningful share of the plan. The calendar is set by the **15 December 2026** defense; the team works flexibly and uses AI assistance.

**Review load (D42):** Ali accepts a higher review share as team leader. Skill fit takes priority over equal review counts; manual decisions are recorded in `assignments.csv`.

**Plan shape:** 53 tasks, 121 complexity points. Target per member: about 10.6 tasks / 24.2 points.
